# CrateScribe

Ranks Waylaid Crates by gold spent per Merchant's Favor, using MarketScribe prices.

An addon for **World of Warcraft: Forever** (interface 16001), made for personal use and shared as-is.

## Install

- **WowUp:** Add Addon → Install from URL → paste this repository's URL. Updates come with each new release.
- **Manual:** download `CrateScribe-<version>.zip` from the Releases page and unzip it so the `CrateScribe` folder sits in `_forever_\Interface\AddOns\`.

Type `/reload` in game after updating.
